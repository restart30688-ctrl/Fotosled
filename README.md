# ФОТОСЛЕД — сборка APK через GitHub

Уличный фото-детектив: сними место → зашифруй фото → отправь дело в чат MAX →
друзья ищут локацию вживую по GPS «горячо-холодно». Отряд 2–8 агентов,
прокачка Новичок → Знаток, гардероб аватаров, рейтинг.

## Сборка (без программирования)

1. Создай репозиторий на github.com (кнопка **New repository**, имя `fotosled`, Public).
2. Загрузи в него ВСЕ файлы этого проекта, сохраняя папки:
   - с компьютера: перетащи папки и файлы в окно «uploading files»;
   - с телефона: открой репозиторий, нажми клавишу `.` (откроется редактор github.dev),
     создай папки `.github/workflows`, `scripts`, `android-res/...`, `www`
     и вставь содержимое файлов, затем Commit.
3. Вкладка **Actions** → workflow **Build FotoSled APK** → **Run workflow**.
4. Через 5–8 минут открой завершённый запуск → внизу **Artifacts** →
   скачай `FotoSled-APK` (zip) → внутри `FotoSled.apk`.
5. Передай APK детям, открой файл на телефоне, разреши «установку из неизвестных
   источников». Приложение альбомное, asks камеру и геолокацию при первом
   использовании — разреши, иначе шифровка фото и GPS-пинг работать не будут.

## Что делает сборка

- Capacitor 6 оборачивает `www/index.html` в нативный Android WebView.
- `scripts/patch-android.mjs` добавляет разрешения CAMERA / GPS,
  фиксирует альбомную ориентацию (`sensorLandscape`), не гасит экран,
  ставит фирменную иконку-радар.
- APK подписан debug-ключом — устанавливается напрямую, без Play Market.
- Кнопка «Чат отряда» открывает ссылку из Настроек (MAX или любой мессенджер).
- Кнопка «Назад» на Android: закрывает окно → закрывает дело → возврат в Штаб.

## Обновление игры

Замени `www/index.html`, сделай Commit — Actions соберёт новый APK автоматически.
